# Changelog 0.5.3

## ⚙️ Dependencies & Compatibility
- **Minecraft / Paper Support**: Updated compatibility targeting Paper `26.1.2`.
- **Java 25 Toolchain**: Aligned build pipeline and toolchain with Java 25.
- **LuckPerms Optional Integration**: Hardened optional checks so server installations without LuckPerms load cleanly without runtime reflection errors.

## 🛠️ Core Services & Improvements
- **Service-Oriented Runtime**: Refined `@DreamAutoService` dependency graph resolution and startup ordering.
- **Visual & NMS Utilities**: Stability improvements to client-side fake blocks and visual glowing pipelines.
