# Changelog 0.5.7

## 🗺️ Navigation & Pathfinding Enhancements

- **Instant Path Calculation**: Navigation tasks (`PathFindingTask` and `ItemDisplayNavigationTask`) now trigger the initial A* search immediately upon start (`triggerRecalc()`), rendering the route on the very first frame without waiting for the player to move.
- **Deviation-Only Recalculation (Zero Flickering)**:
  - Replaced periodic movement-based recalculations with an intelligent deviation check (`distance > recalcMinDistance`).
  - Walking along the route no longer triggers unnecessary A* recalculations.
  - Eliminated the periodic despawn/respawn flickering of `ItemDisplay` entities.
- **Bidirectional Waypoint Tracking**:
  - Waypoint progression now tracks both forward and backward movements within a local window to prevent premature jumps across walls or hairpins.
  - Advancing smoothly clears passed waypoints.
  - Backtracking automatically restores previously passed displays or particles.
- **ItemDisplay Orientation Toggle (`facePlayer`)**:
  - Added a `facePlayer` toggle (`setFacePlayer(boolean)`).
  - When `false` (default): items stay in `Billboard.FIXED` orientation and follow the computed waypoint `yaw` pointing to the next block.
  - When `true`: items dynamically rotate to face the player's camera (`Billboard.CENTER`).
  - Changing orientation immediately updates all existing active displays in real-time.
- **Customizable ItemDisplay Spacing (`spacing`)**:
  - Added a `spacing` setting to display an item every N blocks (default: `1`).
  - Utilizes absolute path indexing so displays remain fixed in the world without shifting or flickering as the player walks.
  - The destination (`endItem`) is always displayed regardless of spacing value.
- **Service & Task API Overloads**:
  - Added new `NavigateService#startItemDisplayNavigation` overloads accepting `spacing` and `facePlayer`.
  - Exposed `triggerRecalc()` on navigation tasks for manual recalculation triggers.
