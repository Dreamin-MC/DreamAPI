# Changelog 0.5.6

## 🗺️ Navigation & Workflow Improvements
- **Item Display Navigation Overloads**: Added a comprehensive set of convenient overloads to `NavigateService#startItemDisplayNavigation`:
  - Minimal variation with a single item across all waypoints and unlimited display radius.
  - Surcharges for customizable `displayRadius`.
  - Surcharges for distinct start, middle, and end items.
  - Surcharges supporting custom tick animators (`Consumer<ItemDisplay>`).
  - Surcharges with `allowedMaterials` and `ignoredMaterials` filtering.
- **`ItemDisplayNavigationTask` Constructors**: Added overloaded constructors mirroring the service methods for direct instantiation.
- **Command Introspection**: Updated `/navigation info` to properly display task-specific details for both `PathFindingTask` and `ItemDisplayNavigationTask`.
- **CI / Release Workflow**: Fixed branch synchronization in the GitHub Actions publish workflow when updating `README.md`.
