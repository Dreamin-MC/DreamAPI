# Changelog 0.5.4

## 🗺️ Navigation & Pathfinding Major Update
- **`AbstractNavigateTask` Base Class**: Centralized pathfinding state into a new abstract class (`extends BukkitRunnable`). Developers can now easily create custom navigation tasks that inherit the core A* logic.
- **Unified Navigation Events**: Consolidated navigation events (`PathFindingStartEvent`, `PathFindingStopEvent`, `PathFindingFinishEvent`, `PathFindingRecalcEvent`, `PathFindingWaypointReachEvent`) to accept `AbstractNavigateTask`. These are now dynamically triggered across all task types (particles, entities, items) instead of being duplicated.
- **`ItemDisplayNavigationTask`**: Introduced a brand-new task type that renders the path using `ItemDisplay` entities instead of particles. 
  - Exclusive visibility (only the target player can see them).
  - Configurable items for the start, middle, and end of the path.
  - Features an API-driven `Consumer<ItemDisplay>` to freely animate items on a tick-by-tick basis.
- **Ignored Materials (`ignoredMaterials`)**: The A* pathfinder now supports a list of materials to completely ignore (treat as air/passable) when calculating routes, useful for pathing through barrier walls or fake blocks.
- **Performance - Display Radius**: Added a `displayRadius` parameter to both `PathFindingTask` (particles) and `ItemDisplayNavigationTask` (items) to limit the rendering distance around the player.
- **Directional Pathing**: Locations returned by the pathfinder now automatically have their `yaw` pre-calculated to point exactly at the next waypoint, providing smooth, natural entity orientation along the route.
- **Command Enhancements**: Updated admin commands (`/navigation start`, `/navigation path`, `/navigation entity move`) to support the new `[ignoredMaterials]` parameter.
