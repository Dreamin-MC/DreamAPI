# Changelog 0.5.5

## 🗺️ Navigation API & Service Enhancements
- **Polymorphic Navigation Tracking**: `NavigateService` now tracks `AbstractNavigateTask` internally instead of strictly `PathFindingTask`. 
  - `getNavigationTasks(Player)` returns `Set<AbstractNavigateTask>`, allowing inspection of all active tasks (particles, item displays, or custom tasks).
  - `stopNavigation(AbstractNavigateTask)` can now stop any active navigation task regardless of its underlying implementation.
- **`startItemDisplayNavigation` Service Overloads**: Added convenient overloaded methods to `NavigateService` for launching item display paths:
  - Simplified call with a single `ItemStack` across all waypoints and unlimited display radius.
  - Surcharges for customizable `displayRadius`.
  - Surcharges for start, middle, and end item differentiation.
  - Surcharges supporting tick animators (`Consumer<ItemDisplay>`).
  - Surcharges with `allowedMaterials` and `ignoredMaterials` filtering.
- **`ItemDisplayNavigationTask` Constructors**: Added overloaded constructors mirroring the service variations for direct task instantiation.
- **Waypoint Reach Event Fix**: Ensured `PathFindingWaypointReachEvent` correctly fires on `ItemDisplayNavigationTask` as players progress along waypoints.
- **Command Introspection**: Updated `/navigation info` to properly differentiate and display task-specific details for both `PathFindingTask` and `ItemDisplayNavigationTask`.
