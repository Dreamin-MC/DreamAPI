# Changelog - dreamapi-nms 0.1.0

## Modular Architecture & Multi-Version Support

- **Independent Sub-Library (dreamapi-nms)**:
  - Multi-version NMS packet reflection (PacketReflection) and VisualService for client-side fake entities and blocks.
  - Merged public API (fr.dreamin.dreamapi.api.*) and runtime implementation (fr.dreamin.dreamapi.core.*) into a self-contained artifact published on JitPack.
- **Multi-Version Compatibility (26.1.2 - 26.4+)**:
  - Full compatibility across Paper 26.1.2, 26.2, 26.3, and 26.4+ with standardized code style and complete Javadoc jar generation.
